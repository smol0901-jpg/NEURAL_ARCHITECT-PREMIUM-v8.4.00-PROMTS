# 🤝 Как добавить новый промт

Каталог построен так, что **витрина `index.html` автоматически подхватывает все промты из `prompts.json`**. Чтобы добавить новый — не нужно трогать HTML, только JSON.

## 📋 Шаг 1. Открой `prompts.json`

Это единый источник правды. Внутри — массив `prompts`, каждый элемент выглядит так:

```json
{
  "id": 56,
  "title": "Название промта",
  "category": "productivity",
  "description": "Короткое описание в 1-2 предложениях.",
  "text": "Активируй NEURAL_ARCHITECT PREMIUM++ v8.4.00 в режиме \"РЕЖИМ\".\nПолный текст промта...\nАвтор: Смолянинов А.В."
}
```

## ✏️ Шаг 2. Добавь новый объект в массив `prompts`

Скопируй последний элемент, поменяй `id` (на следующий по порядку), заполни поля.

### Доступные категории

| `category` | Название на сайте |
|---|---|
| `universal` | Универсальные |
| `marketing` | Маркетинг |
| `business` | Бизнес |
| `programming` | IT и Код |
| `health` | Здоровье |
| `productivity` | Продуктивность |
| `creative` | Творчество |
| `image` | Изображения |
| `education` | Обучение |
| `home` | Дом |

> ⚠️ Если добавляешь новую категорию — не забудь прописать её в `index.html` (кнопка фильтра + словарь `getCategoryName`).

## 📐 Шаг 3. Соблюдай структуру текста промта

Каждый промт начинается с фразы-активатора и заканчивается подписью автора:

```
Активируй NEURAL_ARCHITECT PREMIUM++ v8.4.00 в режиме "НАЗВАНИЕ РЕЖИМА".
[Тело промта с инструкциями, формой ответа, ограничениями]
Автор: Смолянинов А.В.
```

## 🚀 Шаг 4. Закоммить и запушь

```bash
git add prompts.json
git commit -m "feat: add prompt #56 — Название промта"
git push
```

## ✅ Шаг 5. Готово!

Открой `index.html` — новый промт появится автоматически. Если сайт задеплоен на GitHub Pages, обновление подхватится в течение 1-2 минут.

---

## 🌐 Деплой на GitHub Pages

1. Перейди в **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**, folder: **/ (root)**
4. Save

Сайт будет доступен по адресу:
`https://smol0901-jpg.github.io/NEURAL_ARCHITECT-PREMIUM-v8.4.00-PROMTS/`

> 💡 При локальной разработке используй `python -m http.server 8000` или `npx serve`, иначе браузер заблокирует `fetch('prompts.json')` по CORS.

## 🧪 Чек-лист нового промта

- [ ] `id` уникален и больше предыдущего
- [ ] `title` короткий и понятный
- [ ] `description` объясняет результат, а не процесс
- [ ] `category` есть в списке выше
- [ ] `text` начинается с `Активируй NEURAL_ARCHITECT PREMIUM++ v8.4.00 в режиме "..."`
- [ ] `text` заканчивается `Автор: Смолянинов А.В.`
- [ ] В тексте указана структура ответа (что выдаст ИИ)
- [ ] JSON валиден (проверь через [jsonlint.com](https://jsonlint.com))
